# Falcon One APEX

AI Business Development & Growth Intelligence Platform.

This repository contains the original Falcon One Prospect dashboard prototype with the approved APEX product branding and an added Quotations module. The original dashboard layout and styling are retained.

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The GitHub Pages URL will appear on that settings page after publishing completes.

## Current scope

This is a front-end prototype. Dashboard figures and sample companies are illustrative. Database persistence, authentication, live prospect discovery, external company research, email delivery, and production quotation storage require backend integration.
